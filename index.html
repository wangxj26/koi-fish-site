桌宠

先是一只合格的桌面宠物

不是贴在屏幕上的静态壁纸。它会游、会转身、会打盹，点一下有反应，拖起来有惯性—— 106 段手绘动画，够它自己找事做一整天。

  • 106 段动画，自己找事做

    待机呼吸、转身、游走、点击、拖拽，外加 89 段随机小动作：抛接三球、下五子棋、写代码、偷吃零食、原地小憩……歇一会儿再看，它又换了个花样。

  • 点一下就有反应

    点击会弹跳回应并播放 Q 弹音效（可换成自己的 wav），还会随机自言自语。拖动带惯性，甩出去会自己飘回来。

  • 桌面上的 AI 搭档

    独立对话窗口，可接 DeepSeek 或任意 OpenAI 兼容接口：流式输出、Markdown 渲染、多会话管理，会话按角色隔离，换角色不会串话。

  • 看看你的屏幕

    右键「看看屏幕」：截屏连同前台窗口标题交给视觉模型，用它自己的口吻回你一句关心或吐槽，结果同步进对话里，可以接着追问。

  • 跟着音乐冒歌词

    读取系统媒体控制里的当前曲目，气泡里同步显示歌词；遇到不上报进度的播放器，还能用「歌词对齐」手动校正一行。

  • 还能帮你记事

    待办面板随时增删改，到期用气泡提醒（看不到桌宠时走桌面通知）；托盘常驻、双击显隐，右键菜单还能自己编排。

以上都是它自己的动画帧，不是插画。

语音输入

想打字的时候，它立刻变输入法

没有唤醒词、没有额外面板、不用切输入法。按住、说话、松开，就这三步。

  • 长按即说，松手即写

    按住大肥鱼约 0.6 秒唤起录音，松开鼠标 1～2 秒出结果，文字自动键入光标所在窗口，不打断心流。

  • 离线识别，语音不出门

    SenseVoice-Small 在本机 CPU 上跑，录音不联网、不上传，断网也能用，隐私只留在你电脑里。

  • 自带标点，出口成章

    识别结果自动补标点，数字自动规整（「一百二十三」→ 123），说完就是能直接发出的句子。

  • 五语种，混着说也行

    中文、英文、日语、韩语、粤语自动识别，中英混着说也有明显标点与断句。

  • 任意窗口都能输入

    微信、QQ、Word、浏览器输入框都吃；万一目标程序拒绝模拟输入，会自动复制到剪贴板并在面板上提示你 Ctrl+V。

  • 误触也不添乱

    长按了却没说话，不会打出一堆乱字，面板直接提示「未识别到语音」；按 Esc 或点「取消」随时放弃这一句。

怎么用

三步，一次呼吸的时间

  1. 1

    长按大肥鱼

    鼠标按住约 0.6 秒，面板弹出，开始录音。按住不动即可，移动太多会被当成拖拽。

  2. 2

    对着它说话

    正常语速说完整句，面板上会显示已录时长，不用刻意停顿。

  3. 3

    松手，字就出来了

    松开鼠标，本地转写 1～2 秒，文字自动落进光标所在的位置，接着按回车就能发。

玩法

藏在右键菜单里的小花样

菜单还能自己编排：改名字、换图标、挪进子菜单。下面这些是出厂自带的小心思。

  • 边缘探头

    拖到屏幕左右边缘，它会歪着身子探出头来，点一下才肯露全脸。

  • 黄金回旋

    连点越转越快，从一圈 0.7 秒一路加速到 0.2 秒。

  • 拖文件「喂饭」

    把文件拖到它身上会播放吃掉的动画并记个数——不会真的删除你的文件。

  • 生小肥鱼

    菜单一键再开一只，自动避让位置、互不打扰，多只还能共用同一条解码链。

  • 快捷启动

    把常用程序放进右键菜单，两行自定义，随手就开。

  • 锁定位置 / 透明度

    锁定后点不动也拖不走；透明度 10%–100% 随手一拉，保存即生效。

  • 全局快捷键

    AI 对话、看看屏幕、截图提问可各绑一个系统级组合键，别的程序前台也生效。

  • 省电模式

    隐藏或闲置时暂停解码，CPU 接近 0；开机自启一个勾选搞定。

常见问题

你可能想知道的

语音会上传到服务器吗？ +

不会。识别在本机 CPU 上完成（SenseVoice + sherpa-onnx），模型文件也在本地，断网照样用。 只有你主动使用「AI 对话」「看看屏幕」这类需要大模型的功能时，内容才会发给你自己配置的模型服务商。

为什么第一次要下载 226 MB 的模型？ +

高精度中文识别的模型体积本来就大。为了不让安装包再胖一圈，模型做成首次使用时在设置页一键下载， 下载一次永久可用，之后完全离线。

识别不准怎么办？ +

靠近麦克风、避开强噪环境效果最稳。设置页里可以切换识别引擎、调整长按时长； 面板上会显示录入时长，太短的句子容易缺字，建议一句说完再松手。

能输入到哪些程序？ +

任何接受键盘输入的窗口都可以。若目标程序拒绝模拟输入，文字会自动复制到剪贴板， 面板上会提示你按 Ctrl+V 粘贴。

长按没反应、面板没弹出来？ +

先确认托盘图标还在（退出过就重新打开）；长按时按住别动，移动超过约 12px 会被判定为拖拽； 如果目标输入框本身是全屏游戏或受保护窗口，模拟输入可能被系统拦下，这时走剪贴板兜底。

桌宠会不会很吃性能？ +

隐藏桌宠后动画解码与定时器会暂停，CPU 接近 0；桌宠设置里还有「省电模式」可以停掉后台预热。 多只桌宠共用一条解码链，长时间挂着内存也不会一路上涨。

AI 对话和看看屏幕要花钱吗？ +

软件本身免费，语音识别也在本地免费跑。AI 对话、看看屏幕需要你自己填一个模型服务的 API Key， 费用按该服务商的计费走；不填也不影响桌宠和语音输入。

只想用输入法，不想看到桌宠？ +

右键菜单或托盘里可以「隐藏桌宠」，隐藏后仍可从托盘菜单点「语音输入」唤起录音面板， 用完再显示回来即可。
